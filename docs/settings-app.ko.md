# 설정 앱

"모든 앱"의 "설정", 작업표시줄 프로필 메뉴의 머리글(사용자 이름), 바탕화면 우클릭 메뉴의 "화면 설정 열기"로 엽니다. 대시보드 설정, 자기 계정의 프로필, 보안 수단, 정보만 다룹니다.

| 페이지 | 내용 | 권한 |
|---|---|---|
| 프로필 | 프로필 사진(올려서 자르기), 전자 우편과 태그(OMV 사용자 편집 화면의 Tags와 같은 값) 바꾸기, OMV 사용자 편집 화면 열기(관리자) | 모든 사용자 |
| 화면 | 테마(자동·라이트·다크), 바탕화면(기본 배경 또는 올린 이미지), 작업표시줄 아이콘 정렬(가운데·왼쪽) | 모든 사용자 |
| 일반 | 언어(이 브라우저에만 적용)와 애니메이션 | 모든 사용자 |
| 보안 | 이 세션의 확인 수준과 "지금 확인", 패스키·인증 앱·복구 코드 관리, 새 기기에 줄 기기 추가 코드, 패스키로 로그인하는 브라우저([보안 강화 모드](security.ko.md), [패스키로 로그인](passkey-login.ko.md)) | 모든 사용자 |
| 로그인 화면 | 로그인 배경과 대기 연출 켜기·끄기 | 관리자 |
| 기본 화면 | 화면 설정을 정하지 않은 사용자에게 적용할 기본 테마·바탕화면 | 관리자 |
| 서버 | 워크벤치 주소·SMART 확인 시각·웹 터미널 허용 바꾸기([웹에서 바꾸는 값](configuration.ko.md#웹에서-바꾸는-값)), 권한 도우미 상태와 root 권한 상승, 파일 탐색기의 공유 폴더 목록 받기·디스크 최상위 보기·OMV 공유 폴더 권한 따르기·디스크 휴지통 만들기, 가동 설정 현황과 바꾸는 방법 | 관리자 |
| 보안 정책 | 기능별 보안 강화 단계(웹 터미널, root 권한 상승, 파일 탐색기와 그 확인 범위), 패스키로 로그인의 만료 기간, 패스키 공개 주소 상태, 사용자의 인증 수단 초기화 | 관리자 |
| 업데이트 | [업데이트 채널](upgrade.ko.md#업데이트-채널), 새 버전 확인, 커밋 목록과 새 설정, [대시보드에서 업그레이드](upgrade.ko.md#대시보드에서-업그레이드) | 관리자 |
| 정보 | 버전, 라이선스, 오픈 소스 고지 | 모든 사용자 |

- 관리자 페이지는 OMV 관리자 계정에만 보이며, 모든 사용자에게 적용됩니다.
- 배경 이미지는 PNG, JPEG, WebP를 20MB까지 올릴 수 있습니다. 리버스 프록시의 요청 본문 크기 제한도 그보다 커야 합니다([프록시 요구 사항](reverse-proxy.ko.md#프록시-요구-사항)).
- 로그인 배경은 로그인하기 전에 보이는 그림이므로, 대시보드 주소에 접속할 수 있는 누구나 볼 수 있습니다.
- 프로필의 전자 우편과 태그는 OMV 계정 정보입니다. 저장하면 OMV에 "변경 사항 적용" 대기가 생기므로, 관리자 계정은 저장할 때 적용까지 하고(OMV에 미리 적용하지 않은 변경이 있으면 저장하지 않습니다), 일반 사용자 계정은 관리자가 OMV 웹 UI에서 적용해야 합니다. OMV 기본 관리자 계정(`admin`)처럼 시스템 계정이거나 OMV에서 수정을 막은 계정은 바꿀 수 없습니다.
- 비밀번호·그룹 등 나머지 계정 정보와 그 밖의 OMV·운영체제 설정은 OMV 웹 UI에서 바꿔 주세요.
