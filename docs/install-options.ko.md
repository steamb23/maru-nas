# 설치 옵션

English: [Install options](install-options.md)

`./install.sh`의 옵션입니다. 옵션 없이 실행하면 처음에는 설정을 묻고 설치하며, 이미 설치되어 있으면 설치된 설정으로 업그레이드합니다. 흐름은 [설치](install.ko.md), 업그레이드할 때의 동작은 [업그레이드](upgrade.ko.md)에 있습니다.

## 설치 방식

| 옵션 | 설명 |
|---|---|
| (없음) | 설정을 묻고 빌드한 뒤 설치합니다. 이미 설치되어 있으면 설치된 설정으로 업그레이드합니다. |
| `--reinstall` | 설치된 값을 기본값으로 모든 설정을 다시 묻고 다시 설치합니다. 설치되어 있지 않으면 처음 설치와 같습니다. |
| `--upgrade` | 스크립트용입니다. 설치된 설정으로 확인 없이 업그레이드하며, 설치되어 있지 않으면 실패합니다. 새 버전에서 생긴 설정만 묻습니다. |
| `--uninstall` | 서비스, 실행 파일, 설정을 제거합니다([제거](install.ko.md#제거)). |

## 실행 방법

| 옵션 | 설명 |
|---|---|
| `--no-build` | 빌드를 건너뛰고 기존 `bin/maru`(권한 도우미를 설치하면 `bin/maru-helper`도)를 설치합니다. |
| `--service-install` | 빌드 없이 설치 단계만 실행합니다(root 전용). 설정 옵션을 모두 주면 묻지 않고 설치합니다([자동화](install.ko.md#자동화)). |
| `--dry-run` | 설치 단계를 실행하지 않고, 쓸 파일의 바뀌는 내용과 실행할 명령만 보여 줍니다. sudo를 쓰지 않고 시스템을 바꾸지 않습니다. `--no-build`가 없으면 빌드는 실제로 합니다(저장소 안에만 씁니다). |
| `--plain` | TUI 대신 한 줄씩 묻습니다. |
| `--lang LANG` | 안내 문구 언어를 `en`이나 `ko`로 고릅니다. |
| `-h`, `--help` | 사용법을 보여 줍니다. |

## 설정

설정 옵션으로 준 항목은 묻지 않습니다. 업그레이드에 함께 주면 그 항목만 기존 값 대신 씁니다. 질문에서 `-`를 입력하는 항목은 빈 값(`''`)을 주면 같습니다.

| 옵션 | 설명 |
|---|---|
| `--user NAME` | 서비스 사용자입니다(기본값 `maru`). |
| `--listen ADDR` | 수신 주소입니다. `127.0.0.1:8090`, `unix:/run/maru/maru.sock`, 또는 `host:port`를 지정합니다([수신 방식 고르기](reverse-proxy.ko.md#수신-방식-고르기)). |
| `--allow-non-loopback` | 루프백이 아닌 `--listen` 주소를 허용합니다(위험). |
| `--omv-url URL` | OMV 웹 UI 주소입니다(루프백). |
| `--smart-refresh-at HH:MM` | SMART 정보를 매일 다시 가져올 시각입니다. |
| `--workbench-url URL` | 브라우저에서 OMV 웹 UI를 열 주소입니다. 빈 값이면 "OMV 워크벤치" 앱을 숨깁니다([OMV 워크벤치 열기](configuration.ko.md#omv-워크벤치-열기)). |
| `--public-origin URL` | 브라우저가 대시보드에 접속하는 공개 HTTPS 주소입니다(패스키용). 빈 값이면 패스키를 끕니다. |
| `--helper`, `--no-helper` | [권한 도우미](helper.ko.md)를 설치하거나 설치하지 않습니다. 질문의 기본값은 설치입니다. `--no-helper`는 이미 설치된 도우미를 지웁니다. |
| `--elevate-group GROUP` | root 권한 상승에 `openmediavault-admin`과 함께 필요한 그룹입니다(기본값 `sudo`). `--helper`일 때만 씁니다. |
| `--web-upgrade`, `--no-web-upgrade` | 대시보드에서 업그레이드하는 것을 허용하거나 허용하지 않습니다. `--helper`일 때만 씁니다([켜기](upgrade.ko.md#켜기)). |
| `--build-path PATH` | 대시보드에서 업그레이드할 때 빌드에 쓸 PATH입니다. 묻지 않으며, 일반 사용자로 `./install.sh`를 실행할 때마다 git·go·node·npm·make를 찾은 디렉터리로 정합니다. |

## 내부용

대시보드에서 업그레이드가 쓰는 옵션입니다. 직접 실행할 일은 없습니다.

| 옵션 | 설명 |
|---|---|
| `--upgrade-plan` | 기존 설치를 읽기만 하고, 이 버전으로 업그레이드할 때 물어야 할 설정과 수동 재설치가 필요한 이유를 JSON으로 출력합니다. 시스템을 바꾸지 않습니다. |
| `--upgrade-service` | 대시보드에서 업그레이드의 확인·적용 요청 하나를 처리합니다(root 전용). 업그레이드 서비스(`maru-upgrade.service`)가 실행합니다. |
