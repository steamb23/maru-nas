# 파일 탐색기

English: [File explorer](files.md)

"모든 앱"과 바탕화면의 "파일"은 홈 폴더와 OMV 공유 폴더를 둘러보는 창입니다. OMV 계정으로 한 번 로그인하면 모든 공유 폴더를 사용자마다의 파일 시스템 권한으로 봅니다.

파일은 [권한 도우미](helper.ko.md)가 로그인한 사용자의 권한으로 다루므로, 도우미를 설치하지 않았다면 창을 열 때 그 이유를 안내하고 쓸 수 없습니다. 관리자는 [보안 강화 모드](security.ko.md)로 파일 탐색기 앞에 확인을 둘 수 있습니다.

## 보이는 폴더와 권한

- 처음에는 홈 폴더와 공유 폴더가 보입니다. 일반 사용자의 세션으로는 OMV의 공유 폴더 목록을 받을 수 없으므로, 관리자가 로그인할 때 받은 목록을 저장해 씁니다. 공유 폴더를 더하거나 바꾼 뒤에는 관리자가 다시 로그인하거나 설정 앱 "서버" 페이지의 "파일 탐색기"에서 "지금 받기"를 눌러 주세요. 받은 적이 없으면 `/srv` 아래 디스크를 대신 보입니다.
- 무엇을 읽고 쓸 수 있는지는 파일 시스템 권한(소유자, 모드, ACL)을 따릅니다. SSH로 접속할 때와 같은 권한이며, 관리자도 자기 계정의 권한으로 봅니다.
- 파일을 누르면 열리는 정보 패널에서 소유자·그룹·모드·ACL 유무와 내 권한을 볼 수 있습니다. 관리자에게는 OMV의 ACL 편집 화면 링크가 함께 나옵니다.
- 루트 파일시스템의 공유 폴더(openmediavault-sharerootfs, 예: `/kvm`)는 아직 열 수 없습니다.

### OMV 공유 폴더 권한 따르기

OMV 공유 폴더의 권한(Privileges)은 SMB·FTP 같은 서비스의 설정이라 기본으로는 따르지 않습니다. 관리자가 설정 앱 "서버" 페이지에서 "OMV 공유 폴더 권한 따르기"를 켜면(기본 꺼짐) 파일 탐색기에도 SMB와 같은 규칙으로 적용합니다. 위에서부터 먼저 맞는 줄을 따릅니다.

| OMV에서 정한 권한 | 파일 탐색기 |
|---|---|
| 사용자나 속한 그룹 가운데 하나라도 "권한 없음" | 그 공유 폴더가 보이지 않습니다 |
| "읽기·쓰기"가 하나라도 있음 | 쓸 수 있습니다 |
| "읽기 전용"만 있음 | 읽기만 합니다(사이드바에 자물쇠가 보입니다) |
| 정한 권한이 하나도 없음 | 모두에게 열립니다 |

- 파일 시스템 권한도 함께 적용되고, 관리자도 자기 계정의 권한을 따릅니다.
- 켤 때 공유 폴더 목록을 새로 받습니다. 그 뒤 OMV에서 권한을 바꾸면 "지금 받기"를 눌러 주세요. 사용자의 그룹을 바꿨다면 그 사용자가 다시 로그인해야 반영됩니다.
- 대시보드가 거르는 것이므로, 권한 도우미 수준에서 막으려면 OMV에서 공유 폴더의 ACL을 바꿔 주세요.

### 디스크 최상위 보기

관리자가 설정 앱 "서버" 페이지에서 "디스크 최상위 보기"를 켜면(기본 꺼짐) 관리자에게 공유 폴더 밖, `/srv` 아래 디스크의 맨 위까지 보입니다. 공유 폴더 권한 따르기로 숨긴 공유 폴더는 여기서도 열 수 없습니다.

## 보기와 찾기

- 도구 줄 오른쪽 단추로 목록 보기와 아이콘 보기를 바꾸고, 옆의 정렬 단추로 정렬합니다. 고른 보기는 다음에 여는 창에도 이어집니다.
- 수만 개가 든 폴더도 바로 열립니다. 한 폴더에 30만 개가 넘으면 일부만 보입니다. 수정한 날짜·크기순 정렬은 모든 항목의 정보를 읽은 뒤에 바뀌며, 읽는 동안 진행 막대와 취소 단추가 나옵니다.
- 찾기 칸은 지금 폴더의 이름을 거릅니다. 옆의 "하위 폴더까지 찾기"를 켜고 Enter를 누르면 지금 폴더와 그 아래 모든 폴더에서 이름에 찾기어가 든 항목을 위치와 함께 보입니다.
    - 처음 2000개까지 보이고, 읽을 권한이 없는 폴더는 건너뜁니다. 찾는 동안 결과가 차례로 나오고 "중지"로 멈출 수 있습니다.
    - 결과에서 폴더를 열거나 파일을 미리보거나 내려받고, "위치 열기"로 그 항목이 든 폴더로 갑니다.
- 창은 여러 개 열 수 있어 두 폴더를 나란히 볼 수 있습니다. 한 창에서 폴더 안을 바꾸면 같은 폴더를 보는 다른 창도 바로 바뀝니다.

## 미리보기

이미지, 동영상·오디오, PDF, 텍스트 파일은 두 번 누르거나 Enter, 우클릭 메뉴의 "미리보기", 정보 패널의 미리보기 단추로 "미리보기" 창에서 봅니다.

- 브라우저가 열 수 있는 형식만 보입니다. HEIC·MKV 등은 내려받아 열어 주세요. 텍스트는 앞의 1MiB만 보입니다.
- 미리보기 창은 하나이고, 다른 파일을 열면 그 파일로 바뀝니다. 동영상을 보는 동안에는 입력이 없어도 세션이 연장됩니다.

## 내려받기와 올리기

- **내려받기**: 정보 패널의 "내려받기"나 파일의 우클릭 메뉴로 합니다. 브라우저의 내려받기 관리자가 받으므로 끊긴 내려받기를 이어 받을 수 있습니다.
- **올리기**: "올리기"로 파일을 여러 개 골라 지금 폴더에 올립니다. 컴퓨터의 파일을 창으로 끌어 와도 됩니다. 폴더 줄 위에 놓으면 그 폴더에, 빈 곳에 놓으면 지금 폴더에 올립니다. 폴더는 아직 올릴 수 없으며, 함께 끌어 온 폴더는 건너뛰고 알려 줍니다.
- 같은 이름의 파일이 있으면 덮어쓸지 묻습니다. 덮어쓰면 새 파일로 바뀌므로 소유자는 올린 사용자가 됩니다(권한 비트는 되도록 유지). 폴더에 쓸 수 있으면 쓰기 권한이 없는 파일도 덮어쓸 수 있습니다. 리눅스에서 폴더에 쓸 수 있으면 그 안의 파일을 지우고 다시 만들 수 있는 것과 같습니다.
- 올리기가 길어지면 "파일 작업" 창에 올린 양, 속도, 남은 시간이 보입니다. 올리는 동안에는 입력이 없어도 세션이 연장되고, 탐색기 창을 닫아도 이어집니다. "파일 작업" 창을 닫거나 페이지를 떠나면 취소되며, 올리지 못했거나 취소된 파일은 그 창에서 다시 올릴 수 있습니다.
- 전송은 60초 동안 진행이 없으면 끊기고, 한 번에 6시간까지입니다. 이미 시작한 내려받기·올리기는 로그아웃하거나 보안 정책을 올려도 끝까지 갑니다.

## 정리와 휴지통

- 도구 막대의 "폴더 만들기", 우클릭 메뉴의 "이름 바꾸기"와 "삭제"로 폴더를 만들고 이름을 바꾸고 지웁니다. 정보 패널에도 이름 바꾸기와 삭제 단추가 있습니다. 빈 곳을 우클릭하면 폴더 만들기, 올리기, 모두 선택이 나옵니다.
- 사이드바에 보이는 폴더(홈 폴더, 공유 폴더, 디스크)와 그것을 품은 폴더는 이름을 바꾸거나 옮기거나 지울 수 없습니다. 공유 폴더는 OMV에서 다뤄 주세요.
- 여러 항목을 지우거나 옮기면 하나씩 차례로 하며, 오래 걸리면 진행 막대와 "중지" 단추가 나옵니다. 중지하면 하던 항목까지 마치고 멈춥니다. 폴더 하나를 지우는 데 10분이 넘으면 멈추므로, 다시 지우면 남은 항목을 이어서 지웁니다.

### 휴지통

삭제하면 휴지통으로 옮깁니다. 서버의 trash-cli와 같은 곳·형식의 휴지통이라 서버에서 `trash-list`, `trash-restore`, `trash-empty`로도 같은 휴지통을 다룰 수 있습니다. SMB 휴지통(`.recycle`)과는 따로입니다.

- 홈 폴더의 항목은 홈 휴지통(`~/.local/share/Trash`)에, 디스크의 항목은 그 디스크 맨 위의 `.Trash/<uid>`나 `.Trash-<uid>`에 들어갑니다. 다른 디스크로 복사하지는 않습니다.
- OMV 데이터 디스크의 맨 위는 보통 root 소유라 사용자가 휴지통 폴더를 만들 수 없습니다. 이런 디스크에서는 지우기 전에 영구 삭제라고 알립니다. 관리자가 설정 앱 "서버" 페이지의 "파일 탐색기"에서 디스크마다 "휴지통 만들기"를 누르면(root 권한 상승 필요) 그 디스크에 모든 사용자가 쓰는 `.Trash` 폴더가 생기고, 그 뒤로는 휴지통으로 옮깁니다.
- 사이드바 끝의 "휴지통"에서 항목을 원래 위치·지운 날짜와 함께 보고, 되돌리거나 영구 삭제하거나 휴지통을 비웁니다. 원래 위치에 같은 이름이 있으면 되돌릴 때 새 이름을 묻습니다. 고른 항목을 사이드바의 "휴지통"에 끌어 놓아도 휴지통으로 옮깁니다.
- 확인 대화상자에서 "영구 삭제…"를 고르거나 Shift+Delete를 누르면 휴지통을 거치지 않고 지웁니다. 영구 삭제는 되돌릴 수 없으며, 폴더는 안의 파일과 폴더까지 모두 지웁니다.

## 옮기기와 복사

고른 항목을 끌어 폴더 줄, 위쪽 경로, 사이드바의 폴더, 다른 탐색기 창에 놓으면 옮깁니다. 마우스와 펜으로 끌 수 있고, 터치에서는 끌지 않습니다.

- 다른 탐색기 창에서는 빈 곳이나 파일 줄에 놓아도 그 창이 보고 있는 폴더로 옮깁니다.
- 다른 디스크에 놓으면 옮기지 않고 복사하며, 끄는 동안 이름표에 "복사"로 표시합니다. 홈 폴더와 데이터 디스크도 서로 다른 디스크입니다. 읽기만 가능한 폴더의 항목도 다른 디스크로는 복사할 수 있습니다.
- 옮기거나 복사할 곳에 같은 이름이 있으면 그 항목은 건너뛰고 알려 줍니다.
- 복사가 길어지면 "파일 작업" 창에 복사한 양, 파일 수, 속도, 남은 시간이 보입니다. 모두 복사하면 창이 스스로 닫히고, 복사하지 못한 항목이 있으면 이유와 함께 남겨 둡니다. 창에서 복사를 취소하거나 창을 닫으면 복사하던 항목은 지우고 멈추며, 이미 복사한 항목은 남습니다. 탐색기 창을 닫아도 복사는 이어집니다.
- 복사는 내용과 수정한 날짜만 옮깁니다. 권한·소유자·ACL은 올리기처럼 복사할 폴더의 기본값을 따르고, 심볼릭 링크는 링크로 만들며, 폴더 안의 특수 파일(FIFO, 소켓, 장치)은 건너뜁니다.

## 단축키

| 키 | 동작 |
|---|---|
| Enter, 두 번 누르기 | 폴더 열기, 파일 미리보기 |
| Backspace | 위 폴더로 |
| F2 | 이름 바꾸기 |
| Delete | 휴지통으로 옮기기 |
| Shift+Delete | 영구 삭제 |
| Ctrl(macOS는 ⌘)이나 Shift를 누른 채 누르기 | 여러 항목 고르기 |
| Ctrl+A(macOS는 ⌘+A) | 모두 고르기 |
| Esc | 고른 항목 풀기 |

## 기록

권한 도우미의 감사 로그(`journalctl -u maru-helper`)에는 내려받기·미리보기의 결과와, 쓰기 작업(올리기, 폴더 만들기, 이름 바꾸기·옮기기, 복사, 삭제, 휴지통 작업)이 경로와 함께 남습니다. 폴더 목록, 정보 읽기, 휴지통 목록, 하위 폴더 검색은 남지 않습니다.
