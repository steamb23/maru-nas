# 디스크 건강

"모든 앱"의 "디스크 건강"은 디스크마다 SMART 상태와 온도를 보여 주고, 디스크 하나를 고르면 그 디스크의 SMART 상세 정보를 표로 보여 줍니다. 관리자만 씁니다. SMART 설정과 자가 진단 예약은 OMV 워크벤치의 S.M.A.R.T. 화면에서 합니다.

## 디스크 목록

- 왼쪽 목록은 디스크마다 상태(정상, 주의, 위험, 알 수 없음)와 온도를 보여 줍니다. 상태는 OMV가 SMART 값으로 평가한 결과이고, 문제가 있는 디스크가 먼저 옵니다.
- 목록은 하루 한 번(SMART 확인 시각 이후 처음 열 때)과 "지금 확인"을 누를 때만 OMV에서 다시 받습니다. 확인할 때마다 모든 디스크를 읽으므로 잠든 디스크가 깨어납니다. "지금 확인"은 마지막 확인 뒤 1분이 지나야 다시 누를 수 있습니다.
- 확인 시각은 [설정](configuration.md)의 `-smart-refresh-at`이나 설정 앱의 "서버" 페이지에서 바꿉니다.

## 상세 정보

- 목록에서 디스크를 고르면 그 디스크의 SMART 정보를 읽습니다. 잠든 디스크는 이때 깨어나므로 읽는 데 몇 초에서 수십 초가 걸릴 수 있습니다. 그래서 창을 열 때는 아무 디스크도 고르지 않습니다.
- 한 번 읽은 디스크는 창이 열려 있는 동안 다시 골라도 다시 읽지 않습니다. 새 값이 필요하면 "다시 읽기"를 누르세요.
- 창이 좁으면 목록과 상세 정보를 하나씩 보여 줍니다. 상세 정보의 "디스크 목록"을 누르면 목록으로 돌아갑니다.
- 상세 정보는 탭으로 나뉩니다.
    - 개요: 상태 안내, 온도·사용 시간·전원 켠 횟수 같은 요약, 장치 정보(모델, 시리얼 번호, 펌웨어, 용량 등)입니다. SATA 디스크는 재할당·대기 중·수정 불가 섹터 수를, NVMe 디스크는 수명 사용률·예비 공간·미디어 오류를 요약에 보여 줍니다.
    - 속성(SATA): SMART 속성 표입니다. 고장 예고 항목은 현재 값이 임계값 이하로 떨어지면 곧 고장날 수 있다는 뜻입니다. "주의 항목만 보기"로 문제가 있는 항목만 봅니다.
    - 건강 정보(NVMe): NVMe SMART/건강 정보 로그입니다. 위험 경고, 예비 공간, 수명 사용률, 미디어 오류에 점을 달아 상태를 보여 줍니다.
    - 자가 진단: 최근 자가 진단 기록입니다. 자가 진단의 예약과 실행은 OMV 워크벤치에서 합니다.
    - 원문: OMV가 실행한 `smartctl --xall` 출력을 그대로 보여 줍니다. SATA 디스크는 이 탭을 처음 열 때 디스크를 한 번 더 읽습니다.
- 시리얼 번호는 장치 정보와 원문에 보입니다. WWN 같은 다른 식별자는 장치 정보에 보이지 않지만 원문에는 smartctl 출력대로 남습니다. 원문을 남에게 보낼 때는 이런 값을 지우세요.
- [OMV 워크벤치 주소](configuration.md#omv-워크벤치-열기)를 설정했으면 "OMV에서 보기"로 같은 디스크의 S.M.A.R.T. 상세 화면을, 자가 진단 탭의 "OMV에서 예약"으로 자가 진단 예약 화면을 엽니다.

## 한계

- USB 어댑터를 거친 디스크처럼 SMART 정보를 전달하지 않는 장치는 상세 정보를 읽을 수 없습니다.
- 같은 디스크를 다른 창이나 다른 관리자가 읽는 중이면 그 읽기가 끝난 뒤에 이어서 읽습니다.
- 상세 정보에는 smartctl이 낸 값을 그대로 보여 주는 항목이 많습니다. 속성 이름은 흔한 항목만 번역하고 나머지는 smartctl의 이름을 그대로 씁니다. 원시값의 뜻은 제조사마다 다를 수 있습니다.
- OMV 8.6보다 앞선 버전은 NVMe 디스크의 목록 상태를 smartctl의 자체 평가로만 정합니다. 수명 사용률이나 예비 공간이 기준을 넘어도 목록에는 정상으로 보일 수 있으니 건강 정보 탭에서 확인하세요.
- 원문이 아주 길면 앞부분 256KiB만 보입니다.
- smartctl 출력 형식이 달라 NVMe 자가 진단 기록을 표로 읽지 못하면 원문 탭에서 확인하라고 안내합니다.
